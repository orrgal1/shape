Recommended by builder2 while working #8: no typecheck/test wiring exists for shared `applyOps` — the `kind` round-trip check lives nowhere, so future canvas-op fields have no guard.

## Change
A tiny deterministic scripted smoke for `packages/shared/src/index.ts` `applyOps` — follow the repo's existing smoke convention (`packages/bridge/scripts/smoke.mjs`) rather than introducing a test framework. Cover at least:
- accept path: upsert node with `kind`, round-trips into the doc, rev increments;
- one rejection per major class (unknown parent, cycle, bad slug) asserting the structured receipt shape from #5 ({code, subject, supportedFixes non-empty});
- unknown/absent `kind` degrades to default (no receipt).

Wire a package script (e.g. `pnpm --filter shared smoke` or a root script) so it's one command; keep runtime sub-second.

## Acceptance
- One command runs the smoke and prints a pass summary; a deliberately broken expectation fails nonzero.
- No project-wide suites/formatters; no new test framework dependencies.

## Result
Merged to main (a54028a). New `packages/shared/scripts/smoke.mjs` (23 checks, mirrors bridge smoke convention): kind round-trip + rev bump, receipt shape (code/subject.path/supportedFixes/evidence) for op/unknown-parent, op/cycle, op/bad-slug, and unknown/absent `kind` degradation. Shared registered as workspace package `@visual-harness/shared`; one command: `pnpm smoke:shared` (root) or `pnpm --filter @visual-harness/shared smoke`. Runs sub-second; verified a broken expectation exits 1.
